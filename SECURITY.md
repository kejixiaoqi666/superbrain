# Security policy

SuperBrain is an agent cognition and memory library. Do not commit API keys,
OAuth tokens, passwords, private keys, production databases, or personal
conversation data. Configure model credentials through environment variables
or an external secret manager. The project does not promise that an agent is
safe to grant unrestricted host or network access; isolate deployments and
review tools before enabling them.

Please report vulnerabilities privately to the repository maintainers before
opening a public issue.
